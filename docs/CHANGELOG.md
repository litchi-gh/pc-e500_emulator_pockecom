# 変更履歴

リリースはタグ `v0.0.1`〜`v0.1.0` です。

## 未リリース

### 追加

- **Ubuntu（Linux）版**を追加しました。Windows 版と同じ操作のウィンドウで、Ubuntu 24.04 以降で動きます。tar.gz と `.deb` で配布します（[マニュアル 2章](manual/02_LINUX.md)）。
- **コマンドライン `pokecom`** を追加しました。BASIC の1行やプログラムの実行、キー入力、液晶の読み取り、メモリの読み書きなど37の操作を、端末やスクリプトから使えます。Windows・Linux・Mac で動きます（[16章](manual/16_CLI.md)）。
- **MCP サーバー**（`pokecom mcp`）を追加しました。AI のツールからエミュレータを操作できます（[18章](manual/18_MCP.md)）。
- Ubuntu と Mac では、端末に1行貼り付けるだけで入れられる `install.sh` を用意しました。
- **Mac** で `pokecom` が使えるようになりました（Apple シリコンと Intel。[3章](manual/03_MACOS.md)）。
- マニュアルを章に分けて `docs/` に移し、Ubuntu・Mac・コマンドライン・MCP・困ったときの章を足しました。ROM の吸い出しには、周辺機器の要らない [PC-E500 BEEP ROMDump](https://github.com/litchi-gh/pc-e500_beep_romdumper) を案内しています。
- PC-E500S の 384KB ROM に対応しました。384KB の ROM のうち、本体 ROM の機種コード（版の下の桁）が 3 のものを PC-E500S として扱い、内蔵 RAM を PC-E500 と同じ 32KB（選べる容量も同じ）にします。ステータスバーの ROM の欄には「E500S」と出ます。

### 修正

- CE-140F のエラーが、実機と同じ BASIC のエラーになるようにしました（ファイルがないと `File not found`、書き込み禁止は `File write protected`、`NAME` の名前が使えないと `NAME error`、1MB を超えると `Disk full` など）。これまでは、ファイルがないときの `LOAD` が終わらないことなどがありました。
- `KILL` が、フォルダの中のサブフォルダに触れないようにしました。
- 行末が LF だけの BASIC のテキストを `LOAD` できるようにしました。
- CE-126P をつないでいないときの `LPRINT` の説明を直しました（ROM は読み飛ばし、エラーにはなりません）。
- 液晶の BATT の表示シンボルを、ページ 6 の bit0 から読むようにしました。これまでページ 5 の bit7 を読んでいたため、ROM が BATT を点けても表示されませんでした（ROM は作業域 `BFC97h` をページ 6 にそのまま書きます）。
- 384KB の ROM をすべて PC-E650/PC-U6000 として扱い、PC-E500S の ROM でも内蔵 RAM を 64KB にしていたのを直しました。

## 0.1.0（2026-11-24）

### 追加

- 「プログラム読込」を追加しました。PC の BAS（テキストでも、本体で保存した形でも）と BIN（`SAVE M` のヘッダー付き）を、ツールバーかウィンドウへのドラッグ＆ドロップで読み込めます。BAS は CE-140F のフォルダに置いて `LOAD "X:..."` を自動で入力し、BIN はヘッダーのアドレスへ直接書き込みます。
- 「画面」に「残像（フレーム補完）」を追加しました（既定は入）。ドットが点く・消えるのを数コマかけて変え、1ドットずつ動くもの（ゲームの自機や流れる星など）は、前の位置から次の位置へなめらかに滑らせて描きます。リアル表示のドットの間の線は動きません。動いている絵は、最大で1歩ぶん遅れて表示されます。
- 「設定」に「自動電源OFF」を追加しました。外すと、キーを押さずに放っておいても本体の電源が切れません（ESP32 版と同じ仕組み）。
- 機械語エリアの確保を追加しました。ステータスバーの「機械語」の欄（右クリックのメニューにも）で大きさを決めると、本体の ROM の処理（`POKE &HBFE03,...:CALL &HFFFD8`）を自動で入力して確保し、BASIC に戻します。ウィンドウには内蔵 RAM の並びが「今」と「適用後」の帯で出ます。今の大きさはステータスバーに出ます。
- 「プログラム読込」で機械語エリアの外に入る BIN を読み込むとき、BASIC に上書きされないよう、先に機械語エリアを確保するかを聞くようにしました。「はい」で確保が終わってから書き込みます。BIN の範囲が今ある内蔵 RAM か RAM カードに入っていないときは読み込みません。BASIC のプログラム・変数・スタック・作業域・システムなど使用中の所にかかるときは、そのままでは書かず、機械語エリアとして先に確保できるときだけ「確保してから読み込む」を選べます。読み込みは1つずつです。
- デバッグウィンドウに、内蔵 RAM（と RAM カード）の並びを色分けしたメモリマップを足しました。区画を押すとメモリの表示がそこへ飛びます。
- デバッグウィンドウのメモリ表示を、1行 16 バイトと 8 バイトで切り替えられるようにし、8 バイトごとにチェックサム（和の下位 8 ビット）を付けました（`XX ×8 : XX  - XX ×8 : XX`）。
- 「プログラム読込」で、本体で保存した形の BAS は RAM に直接書き込むようにしました。`LOAD` を打たず、CE-140F も BASIC のモードもいりません。結果は、同じファイルを `LOAD` したときと区画の中身まで同じです（テキストの BAS とパスワード付きのファイルは、これまでどおり `LOAD` を入力します）。
- 「プログラム読込」のファイルを選ぶウィンドウに「読み込んだら実行する（BAS は RUN）」を追加しました。印を付けると `LOAD "X:...",R` で読み込んでそのまま実行します。印は覚えておき、ドラッグ＆ドロップにも効きます。
- 「設定」と右クリックのメニューに「常に手前に表示」を追加しました。メインウィンドウがほかのウィンドウの下に隠れなくなります。
- ゲームコントローラーに対応しました。ツールバーの「コントローラー」で、パッドの絵（押したボタンが光る）と「押しているボタン」を見ながら、ボタンごとに本体のキー（SHIFT・CTRL 付きも）を割り当てられます。プリセットは追加・名前の変更・削除ができ、「テンキー 2・4・6・8」（既定）と「カーソルキー」を用意しました。XInput（Xbox 系）と DirectInput のパッドに対応し、DirectInput は「ボタンの位置合わせ」でボタンの番号の位置を合わせられます。設定は state/controller.json に保存します。使っている間、ステータスバーに「コントローラー 接続中／未接続」が出ます。パッドはメインウィンドウが前にあるときだけ効きます。
- CPU の AMC（番地変換）に対応しました。RAM カードを内蔵 RAM の直前へつなぐアクセスを再現します。カードのイメージファイルと状態ファイルの形式は変わりません。
- 見た目を Windows 11 の作りにしました。ツールバーはアイコン付きのボタン、右クリックのメニューは角の丸い作りに、各ウィンドウのボタンは角の丸いもの（Enter で押すボタンはアクセントカラー）にしています。「設定」の「テーマ」で、Windows に合わせる（既定）・ライト・ダークを選べます。

### 変更

- PC のキーを押している間は、本体のキーも押したままにするようにしました（実機の長押しと同じ）。これまでは Windows の自動リピートを短い連打として送っていたため、押し続けても本体には押しっぱなしが伝わりませんでした。押し続けて繰り返すかは ROM が決めます（BS・DEL・←→ は繰り返し、文字は1回）。
- 画面を、ディスプレイの書き換えに合わせて1回ずつ描くようにしました。これまでは1秒に62.5回描いていたため、60Hz の画面では0.4秒ごとに1コマ飛び、動きが引っかかっていました。残像（フレーム補完）も弱め、消えるドットが尾を引かないようにしました（約 0.01 秒・0.02 秒）。
- ウィンドウの下の状態の行を、欄に分かれたステータスバーにしました。左端に本体の状態（色の点つき。押すと一時停止・再開）、その横にメッセージ、右側に ROM・メモリ・CE-140F・CE-126P・音声の欄を並べます。欄にマウスを乗せると詳しい内容が出て、メモリの欄は「設定」、CE-140F・CE-126P の欄はそれぞれのウィンドウを開き、音声の欄は消音を切り替えます。ROM の容量やカードのファイル名は、欄を短くするためヒントに移しました。
- 速度の切り替えを、ツールバーのボタンからステータスバーの右端の欄（「速度 1x」など。押すと切り替わる）に移しました。
- ツールバーの「保存」「読込」を「ステータス保存」「ステータス読込」に改めました（「プログラム読込」と紛れないように）。
- 本体の下にあった操作の案内の行（「初回 PF1 → BASIC …」）をなくしました。
- デバッグウィンドウのレジスタを、文字の行から欄を並べた表示にしました（状態は色付きの印、フラグは点く印）。
- デバッグウィンドウの「チェックサム」ボタンと、範囲を指定して計算するウィンドウをなくしました（8 バイトごとのチェックサムをメモリ表示に付けたため）。メモリ表示の右側の文字（ASCII）の欄もなくしました。
- サブウィンドウの作りをそろえました。中身は見出し付きの面に分け、ボタンは下の帯に右寄せで並べます。「設定」は「表示」「本体」「CE-140F」「音・電源・その他」に分け、各ウィンドウの説明文を短くしました。
- ステータスバーの欄が入りきらないとき、順に短い表記（「未接続」「1x」など）にするようにしました。メモリの欄は「RAM 32KB」（カード付きは「RAM 32KB+64KB」）に縮めました。
- 「設定」「コントローラー」「文字入出力」「CE-126P」のウィンドウは、横に広げても中身が変わらないので、横には広げられないようにしました（縦は変えられます）。「デバッグ」は狭くはできますが、最初の幅より広くはなりません。
- メインウィンドウの地の色は、これまでの紺に近い色から、テーマ（ライトかダーク）の色になりました。本体だけの表示の透ける色は、これまでと同じです。

### 修正

- 「BIN書込み」「BIN書出し」のウィンドウで、「参照」ボタンが欄の外にはみ出して見えず、「キャンセル」も右端で切れていたのを直しました。「設定」のボタンの下が切れていたのも直しました。
- 「ROMを開く」で rom フォルダの外の ROM を開いて使っていると、次の起動で ROM が開かれず、毎回開き直す必要があったのを直しました（インストール版は rom フォルダが空で始まるため、起きやすくなっていました）。最後に開いた ROM を覚えて、次の起動でも開きます。

## 0.0.5（2026-11-14）

### 追加

- CE-126P の印字を、プリンタにも送れるようにしました。「CE-126P」ウィンドウの「印刷先」で、USB のサーマルプリンタ（58mm・ESC/POS。ドライバなしで直接、1行ずつ印字し、3秒止まると紙を送る）か、Windows のプリンタ（3秒止まったところで、それまでの行を実寸でまとめて印刷）を選べます。「紙を印刷」で紙の全体も印刷できます。
- リリースの本文に、zip とインストーラーの SHA-256 を載せるようにしました（`package.ps1` が書き出します）。ダウンロードしたファイルを `Get-FileHash` で確かめられます。

### 変更

- CPU の速さを実機と同じにしました（1 秒あたり 768,000 サイクル。これまでは 1,024,000 サイクルで、実機より約 33% 速く動いていました）。BASIC や機械語のプログラムが実機と同じ速さで動きます。速くしたいときは、速度の倍率を上げてください。以前の版で保存した状態も読み込めます。
- 画面の描画を軽くしました。LCD が変わったときは LCD の部分だけ、キーを押したときはそのキーの部分だけを描き直します。大きなウィンドウでは、1コマの描画が約21msから約1.5msに、キーを押したときが約52msから約1msになり、キーの反応・音・動きが遅れにくくなりました。
- 自動保存（5秒ごと）のファイルの書き込みを、画面の処理とは別のスレッドで行うようにしました。保存のたびに一瞬止まることがなくなります。内蔵 RAM・RAM カード・状態は、中身が変わっていなければ書き直しません（電源を切って置いておいても、OneDrive に同期が続かなくなりました）。
- キー待ち（HALT）や電源 OFF の間の処理を軽くし、何もしていないときの PC の負荷を下げました。
- コントラストのスライダーを動かしたときや、リアル表示で LCD が変わったときの描画を軽くしました。
- PC の Ctrl を押しながらキーを打つと、本体の CTRL 付きのキーとして入力するようにしました（Ctrl+英字も使えます）。
- 貼り付けの入力の途中でほかのウィンドウに移ったりツールバーを使ったりしても、入力を続けるようにしました。
- 状態ファイルの形式を新しくしました（ROM の確認を加えたため）。前の版で保存したファイルはそのまま読めますが、この版で保存したファイルは 0.0.4 以前では読めません。

### 修正

- 割込みを止めて動く機械語のプログラムを `CALL` で始めると、ENTER のキークリック音が鳴り続けることがあったのを直しました。CPU が実機より速く、クリック音を止める割込みより先にプログラムが始まっていたためです。
- 自動保存でファイルに書けないとき（OneDrive の同期中など）、エミュレータが一時停止して「実行停止」のメッセージが出ていたのを直しました。止めずにステータスバーに知らせ、次の回にもう一度保存します。
- 設定ファイルが壊れていると、起動するたびにエラーになり使えなくなっていたのを直しました。壊れたファイルは別名で残し、既定の設定で起動します。受け付けない値が1つだけのときは、その項目だけを既定値にします。
- 状態を「読込」して内蔵 RAM の容量が変わったとき、次の起動で元の容量に戻っていたのを直しました。
- 終了するとき、まれにアプリが落ちることがあったのを直しました（音声の出力の後片付け）。
- 暴走したプログラムが特定のバイト（'0'〜'7' など）の並びに飛ぶと、アプリごと落ちることがあったのを直しました。
- ROM の切り替えや起動で RAM のファイルを読めなかったとき、空の RAM のまま動き、自動保存が利用者の RAM ファイルを上書きしてしまうことがあったのを直しました。読めなければ、それまでの状態のまま止めます。
- 設定で、装着中のカードと同じファイルに新しいカードを「作成」すると、すぐに元の中身で書き戻されていたのを直しました（そのファイルには作れないようにしました）。
- BIN の書き込みで、RAM より大きいファイルが折り返して自分の先頭を上書きしたまま「書き込みました」となっていたのを直しました。ファイル名を手で書き換えたとき、前に選んだファイルを書いていたのも直しました。
- バイナリエディタで、Ctrl+C などを押すと RAM に書き込んでいたのと、1桁目を打った時点で書き込んでいたのを直しました（2桁そろってから書きます）。タッチパッドでもスクロールできるようにしました。
- CE-140F：テキストの SAVE と PRINT# が、大きなファイルで遅くなっていたのを直しました。`OPEN ... FOR APPEND` で新しいファイルを作れるようにしました。FILES が変わった名前のファイル1つで失敗していたのと、INIT が小文字の名前のファイルを消さなかったのを直しました。拡張子のない名前、`COMP.BAS` のような名前、CR だけで終わる行を扱えるようにしました。`LOAD M` でちょうど 256 バイトの倍数のファイルを読むと、5秒後にエラーになっていたのを直しました。
- 初めて起動したとき、英語の Windows でも日本語で表示されていたのを直しました。
- zip 版を、上のフォルダに `rom` があるフォルダに展開すると、そこをデータの置き場と間違えていたのを直しました。
- キーを押したとき、ケースに印刷された文字（キーの上の文字など）まで一緒に下がっていたのを直しました。
- ステータスバーのメッセージ（貼り付けの結果、オールリセットの案内）が、すぐに消えていたのを直しました。
- CE-126P のプリンタへの送り出し：USB のプリンタを抜き差ししたり別の差し込み口に移したりすると印字できなくなっていたのと、紙切れなどで止まったままになっていたのを直しました。「紙を印刷」で直前の行が二重に印刷されていたのと、印字の間隔が短いと Windows のプリンタに出なかったのを直しました。

## 0.0.4（2026-11-03）

### 追加

- CE-126P（11ピンのサーマルプリンタ）に対応しました。ROM のプリンタドライバがそのまま動き、`LPRINT`・`LLIST`・`PRINT=LPRINT` が24桁で印字されます（♠♥♦♣・円年月日などの記号も）。CE-140F と同時につなげます。
  - ツールバーの「CE-126P」ボタンで紙のウィンドウを開き、テキストや PNG で保存・コピーできます。
  - 「接続」を外すと、実機でプリンタをつないでいないときと同じく、ROM が `LPRINT` などを読み飛ばします（エラーにはなりません）。接続の状態は設定に残り、ステータスバーにも表示します。
- 右クリックのメニューを追加しました。ツールバーと同じ操作に加えて、速度、ウィンドウの表示、最小化・終了があります。
- ウィンドウの表示を3種類にしました。本体のキーのない所をダブルクリックすると「通常 → 本体だけ → 画面だけ → 通常」と切り替わります。
  - 本体だけ：枠やタイトルバーのない、本体の絵だけのウィンドウです。
  - 画面だけ：液晶の部分だけのウィンドウです。
  - 枠のない表示では、絵をドラッグして動かし、縁をドラッグして大きさを変えられます（縦横の比は保ちます）。表示・大きさ・位置は次の起動に引き継ぎます。
- ツールバーに「画面」ボタンを追加しました。
  - 液晶の表示：標準（ドットを詰める）とリアル（実機のようにドットの間をあける）を選べます。
  - 液晶のコントラスト：0〜100 で変えられます（50 が今までの濃さ）。実機と同じく、消えている表示シンボルも一緒に薄く・濃くなり、100 では全体が黒くなります。
- 新しい版のお知らせを追加しました。起動時に1日1回まで GitHub の最新リリースを確かめ、新しい版があればツールバーとメニューに表示します。変更点と更新のしかたを示すだけで、ダウンロードや置き換えはしません。「設定」で止められます。
- インストーラーを追加しました（zip と両方を配布します）。「自分だけ」か「すべてのユーザー」かを選べます。インストール版のデータ（ROM・RAM・設定・状態）は `%LocalAppData%\PockeComE500\` に置きます。右クリックのメニューの「データフォルダを開く」で開けます。
- `¥`・`¦` を貼り付けや入力で使えるようにしました（SHIFT+G・SHIFT+H と同じ文字になります）。
- ウィンドウのタイトルに、アプリの版を表示するようにしました（例：`PC-E500 Emulator v0.0.4 | PokeCom`）。
- 対応機種に PC-E550・PC-1480U・PC-1490U・PC-1490UII（256KB ROM、外観は PC-E500）を加えました。rom フォルダからの自動の選択も、これらの名前の ROM を選びます。同じ機種の ROM が複数あれば、名前の順で最後のもの（`PC-E500(7.2).ROM` のような「機種名(版).ROM」なら新しい版）を選びます。

### 変更


- 「設定」の「LCDのドット間に線を表示」を、「画面」のリアル表示に移しました。前の設定は引き継ぎます。
- 液晶の表示シンボルと本体の文字を、実機の写真に合わせて描き直しました。
  - DEG・GRAD・RAD を実機と同じ区切りで表示し、`SMALL` を `小文字` にしました。
  - BATT を、実機と同じ電池の形にしました。
  - SHARP のロゴ、型番、キーの上の記号（`¥`・`¦`・`x√y`・`÷/`・`×*` など）、「 」・、。・ の位置と形を実機に合わせました。
  - PC-E500 の文字キーの段のずれ方と、RESET の穴・ON キーの位置を実機に合わせました。
- 印字の途中でも、状態の保存・設定の変更・オールリセットができます。読み込むと、その行の続きから印字します。
- 状態ファイルの形式を新しくしました。前の版で保存したファイルはそのまま読めます。ただし、この版で保存したファイルは 0.0.3 以前では読めません。
- 説明書（日本語・英語）・README・`app/README.txt` を今の機能に合わせ、画像を撮り直しました。README は見どころと動作環境をまとめた概要にし、実機（CE-140F のエミュレータ（ハード））とテキストのファイルをやり取りするときの注意を加え、詳しい使い方は `MANUAL.md`（英語は `MANUAL_en.md`）に分けました。

### 修正

- CE-140F：最後に 1Ah（EOF）が付いた ASCII形式のファイルを LOAD すると、Disk full になっていたのを直しました。ファイルの中の 1Ah を終わりとして扱います。保存は今までどおり 1Ah を付けません（CE-140F のエミュレータ（ハード）と同じで、1Ah 付きのファイルはハードのエミュレータでは読めないため）。
- CE-140F：ASCII形式のファイルで、最後の行に改行（CR）がないと、その行が読み込まれずに落ちていたのを直しました。PC で作ったファイルによくある形です。
- CE-140F：`FILES "X:"` で、名前が8文字に満たないファイル（`A.BAS` など）が一覧に出なかったのを直しました。ROM が送る `????????.???` の `?` を、実機と同じく空白にも合うものとして比べます。
