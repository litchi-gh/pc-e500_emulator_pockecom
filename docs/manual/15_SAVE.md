# 15. 保存と復元

- RAMは5秒ごと、OFF時、アプリ終了時に保存し、電源を切っても保持します。異常終了時は最後の自動保存まで戻る場合があります。
- 以下のパスはデータフォルダ（下の表）からの位置です。
- 内蔵RAMの内容は `state/memory/<ROMのSHA256>/internal-容量KB.ram` に、RAMカードの内容は装着中のイメージファイル自身に保存します。
- CPU・内蔵RAM・LCD・タイマーと、プリンタ・CE-140F のバス上の状態のスナップショットは `state/<ROMのSHA256>.i内蔵容量-cカード容量.e500state` に自動保存します。設定は `state/settings.json` に、コントローラーのプリセットと割り当ては `state/controller.json` に保存します。
- 「ステータス保存」「ステータス読込」で任意のスナップショットを保存・復元できます。読込時は保存時の内蔵RAM容量にも戻ります。RAMカードはスナップショットの復元対象外で、装着中のイメージファイルの内容がそのまま使われます。保存時と容量の異なるカードを装着していると読み込めません。未装着で保存したものは未装着で読み込んでください。
- CE-140Fの通信中・ファイルOPEN中はCPUスナップショットを保存・復元できません。`CLOSE` 後に操作してください。RAMファイルの自動保存は継続します。仮想ディスクのファイルはスナップショットの復元対象外です。
- 「オールリセット」は直前の状態を `state/before-reset-日時.e500state` に保存してから実行します。RAMカードは保持します。
- 保存ファイルはハッシュを検証し、一時ファイルから置き換えます。ROM本体は含みません。
- 状態ファイルの形式は版4（中身は `E500ST05`。ROM の容量とチェックサムを含み、別の ROM の状態は読みません）です。0.0.4 の版3（`E500ST04`）と、0.0.3 までの版1・版2（`E500ST01`・`E500ST02`）も読めます。新しい版のエミュレータで保存したファイルは古い版では読めず、0.0.4 以降はその旨を表示します。他のエミュレータとの互換性はありません。

## データフォルダ

| 入れかた | 場所 |
|---|---|
| Windows：インストーラー | `%LocalAppData%\PockeComE500\` |
| Windows：zip | `PC-E500.exe` のあるフォルダ |
| Windows：ソースからのビルド | `app\` |
| Ubuntu：`--deb` | `~/.local/share/PockeComE500/` |
| Ubuntu：`--deb` なし | `~/pockecom/Emulator/` |

右クリックのメニューの「データフォルダを開く」で開けます。

コマンドラインの `pokecom` はここの RAM や設定を読み書きしません（ROM だけは、利用者のデータフォルダの `rom` も探します）。続きから動かすには [`--state`](16_CLI.md#状態を引き継ぐ--state) を使います。状態ファイルはどのシステムでも同じ形式です。
