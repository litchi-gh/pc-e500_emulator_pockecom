# 20. 困ったとき

## 起動と ROM

| 症状 | 対処 |
|---|---|
| ROM を選ぶように出る、「ROM が見つかりません」と出る | ROM は含まれていません。[4章](04_ROM.md)のとおり `rom` フォルダに置くか、「ROMを開く」で選びます |
| ROM を吸い出す機器がない | 音で吸い出す [ROMDump](https://github.com/litchi-gh/pc-e500_beep_romdumper) が使えます（[4章](04_ROM.md#romdump音で吸い出す)） |
| ROM を開けない | 大きさが 256KB（256KB+16 も可）か 384KB かを確かめます。PC-E500S・PC-E650・PC-U6000 で `SAVEM` を使ったときは、2つのファイルを[結合](04_ROM.md#savem-で吸い出すtoolsmerge_savem_rompy)してから開きます |
| `S1(MAIN): NEW CARD`（アタラシイ カードデス）と出る | 初めての起動では正常です。PF1（F1）で初期化します（[5章](05_FIRST_STEPS.md)） |
| Ubuntu で `pc-e500` が起動しない | 端末から起動して、出るメッセージを見ます。足りないライブラリがあるときは、[2章](02_LINUX.md#入れかた)の1行に `--deb` を付けて入れ直すか、`sudo apt install libx11-6 libice6 libsm6 libfontconfig1 libasound2t64` を試します |
| Ubuntu で日本語が □ になる | `sudo apt install fonts-noto-cjk` |
| Mac で「開発元を確認できない」と出る | ブラウザでダウンロードしたものです。[3章](03_MACOS.md#入れかた)の1行で入れ直すか、`xattr -dr com.apple.quarantine ~/pockecom/Emulator` を実行します |
| 入れるときに「最新のリリースに、名前が … で終わるファイルがありません」と出る | その環境のファイルが、最新の[リリース](https://github.com/litchi-gh/pc-e500_emulator_pockecom/releases)に載っていません |
| 入れたのに `pokecom` や `pc-e500` が「見つかりません」になる | 新しい端末（ターミナル）を開きます。PATH は、開いたときに読まれます |

## 使っているとき

| 症状 | 対処 |
|---|---|
| キーを押しても反応しない | 電源が切れていないか（ステータスバーの左端が灰色）を見ます。Esc（ON/BRK）で入ります。一時停止（黄色）なら、そこを押すと再開します |
| 放っておくと電源が切れる | 実機と同じです。「設定」の「自動電源OFF」で止められます |
| 行番号付きのプログラムを入れると `Syntax error` | RUN 表示のままです。BASIC（F7）を押して PRO 表示にします |
| 音が鳴らない、途切れる | 消音になっていないか、速度が 1x かを確かめます |
| `LPRINT` が何もしない | CE-126P の「接続」が外れています。このとき ROM はエラーを出さずに読み飛ばします（[12章](12_CE-126P.md)） |
| 「ステータス読込」ができない | 保存したときと同じ ROM、同じ容量の RAM カードにします（[15章](15_SAVE.md)） |
| 動かなくなった | RESET 穴を押します。データは残ります。戻らなければ「オールリセット」です（[6章](06_KEYS.md#リセット)） |

## CE-140F（X:）

| 症状 | 対処 |
|---|---|
| `File not found` | 名前と、「設定」の保存先のフォルダを確かめます。ファイル名は 8.3 形式です。サブフォルダの中は見えません |
| `File write protected` | 「書込み禁止」か、ファイルの読み取り専用を外します |
| どの命令でも `I/O error` になる | CE-140F が「接続」になっているかを確かめます |
| 実機でテキストの LOAD の最後にエラーが出る | [10章](10_PROGRAMS.md#実機とのファイルのやり取り)を見てください。通常の形（`,A` なし）で渡します |

エラーの一覧は [11章](11_CE-140F.md#エラー)、通信の様子は「CE-140F」のウィンドウ（コマンドラインでは `drive-trace`）で見られます。

## プリンタとコントローラー

| 症状 | 対処 |
|---|---|
| Ubuntu で USB のサーマルプリンタに印字できない（許可がない） | `sudo usermod -aG lp $USER` を実行して、ログインし直します |
| Ubuntu で CUPS のプリンタが並ばない | `lpstat -e` に出るかを確かめます（`cups-client` が要ります） |
| パッドが効かない | メインウィンドウを前にします。「コントローラーを使う」と「使うもの」を確かめ、「再検索」を押します |
| ボタンの位置が合わない | 「ボタンの位置合わせ...」で合わせます（[13章](13_CONTROLLER.md)） |

## コマンドラインと MCP

| 症状 | 対処 |
|---|---|
| 終了コード 3（時間内に終わらない） | 入力待ちか、終わらないプログラムです。`--input` で答えを渡すか、`--seconds` を延ばします |
| 終了コード 4（BASIC のエラー） | エラーの文が標準エラー出力に出ます。プログラムを直します |
| 結果が4行しか出ない | 液晶は4行です。`LPRINT` で出すと、すべて表示されます |
| 前に入れたプログラムが消えている | 本体は毎回まっさらです。`--state` で引き継ぎます（[16章](16_CLI.md#状態を引き継ぐ--state)） |
| Windows の PowerShell で `"` がうまく渡らない | プログラムをファイルに書いて渡すか、`-` で標準入力から渡します。`script` のファイルに書く方法もあります |
| AI のツールからつながらない | [18章](18_MCP.md#つながらないとき)を見てください |
