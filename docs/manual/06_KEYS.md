# 6. キー操作とリセット

画面のキーをクリックするか、PCのキーボードを使います。英字は大文字としてポケコンのキーに送ります。入力は実機と同じくキー行列を通して順次処理します。

ROMは64Hzでキー行列を走査するため、1キーあたり約55ms（毎秒18キー程度）が上限です。PC のキーを押している間は、本体のキーも押したままになり、離すと離れます（実機の長押しと同じ）。押し続けたときに繰り返すかは本体の ROM が決めます。BS・DEL・←→ は繰り返し、文字や数字は1回だけです。実際に打鍵した分は捨てないため、速く打っても文字は落ちません。

| PCのキー | PC-E500の操作 |
|---|---|
| 英数字、空白、演算子 | 対応するキー |
| Enter / Backspace / Delete / Insert | ENTER / BS / DEL / INS |
| 矢印 | カーソル移動 |
| F1〜F5 | 機能キー |
| F6 | MENU |
| F7 | BASIC、RUN/PRO切替 |
| F8 | 2ndF |
| Esc | ON/BRK |
| Ctrl | CTRL |
| Shift | SHIFT |

画面上の **SHIFT** と **CTRL** はクリックすると次の1キーまで保持します。再クリックで解除できます。

PCから入力した `"`、`:`、`$` などの記号は、7.3 ROMの変換表に合わせてSHIFT操作に変換します。ROMはキー行列の1つ前の走査からSHIFTを読むため、SHIFTは文字キーより1走査（約23ms）先に押し、離すのも1走査後にしています。日本語IMEの文字列入力には対応していません。

## リセット

実機と同様に、BASICキーとAキーの間に小さな **RESET穴** があります。画面では穴の周囲もクリックできます。リセットは2種類あります。

| 操作 | 動作 |
|---|---|
| RESET穴 | CPU・LCD・キー・外部バスのみ再起動。データは残ります |
| 「オールリセット」 | 実機のON＋RESETと同じ。ROMが `S1(ナイゾウ): スベテノ データヲ ショウキョ シマスカ? (Y/N)` を表示し、Yで全消去、Nで元のデータのまま復帰します |

「オールリセット」はROMのリセット処理にON/BRKキーを押したまま入るだけの操作で、消去するかどうかの判断とその実行はROM側の処理です。直前の状態は `state/before-reset-日時.e500state` に保存します。内蔵RAMを消したいときはオールリセットにYで答えてください（実機と同じ手順です）。
