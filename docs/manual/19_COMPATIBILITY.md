# 19. 対応範囲と、環境ごとの違い

SC62015命令実行、256KB ROM（PC-E500・PC-E550・PC-1480U・PC-1490U・PC-1490UII）と384KB ROM（PC-E500S・PC-E650・PC-U6000）、内蔵RAM／RAMカードとミラー、HD61102液晶2個（240×32ドット）、キー行列、タイマー割込み、ON/BRK・OFF、0.5/1/2/4倍速、状態保存・復元、BEEP、フォルダ型CE-140F、CE-126Pプリンタを実装しています。

**未対応:** CE-126P以外のプリンタ、カセット、RS-232C/UART、RTCなど。全命令・全BASIC命令・実機同等のタイミングを網羅検証したものではありません。LCDのBUSY時間は省略しています。機械語プログラムや周辺機器を使うプログラムには追加検証が必要です。

PC-E500・PC-E500S・PC-E550・PC-1480U・PC-1490UII・PC-E650・PC-U6000 の ROM で動作確認済みです。

## 環境ごとの違い

本体の動き（CPU・ROM の処理・周辺機器）は、どの環境でも同じコードです。

| 機能 | Windows | Ubuntu | コマンドライン（Windows・Ubuntu・Mac） |
|---|---|---|---|
| ウィンドウ・キーボード・マウス | ○ | ○ | －（キーは `key`・`type`） |
| 設定・画面・デバッグなどのウィンドウ | ○ | ○ | －（同じことをコマンドで） |
| 音 | ○（winmm） | ○（ALSA） | WAV に録る（`record`） |
| CE-140F（X:） | ○ | ○ | ○（`--disk`） |
| CE-126P の紙 | ○ | ○ | ○（`printed`） |
| プリンタへの印刷 | USB サーマル、Windows のプリンタ | USB サーマル、CUPS | － |
| ゲームコントローラー | XInput・DirectInput | ジョイスティック（`/dev/input/js*`） | － |
| 状態ファイル・RAM カード | ○ | ○ | ○（`--state`・`--card`） |
| 内蔵 RAM・設定の自動保存 | ○ | ○ | － |
| 新しい版のお知らせ | ○ | ○ | － |
| MCP（AI から使う） | － | － | ○（`pokecom mcp`） |

Mac には、ウィンドウのあるエミュレータはありません（[3章](03_MACOS.md)）。
